# Daily-Household-Expenses-Management-and-Analysis-Using-SQL-Project
Domain: SQL | Database Management | Data Analytics
Description: Developed a PostgreSQL-based household expense management system to efficiently record, update, delete, and analyze daily expenses. Utilized SQL queries, aggregate functions, and database operations to perform month-wise spending analysis, identify expenditure trends, and uncover major expense categories for better financial insights. 
Technologies: SQL, PostgreSQL 
Tools: PostgreSQL, pgAdmin4 
Techniques: SQL Queries, CRUD Operations, ALTER, DROP, Aggregate Functions, Monthly Expense Analysis
